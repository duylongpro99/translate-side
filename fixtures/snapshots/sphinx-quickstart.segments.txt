  Getting started
0bg1dpptky7 p /html[1]/body[1]/div[3]/div[2]/section[1]/p[1]
  Sphinx is a *documentation generator* or a tool that translates a set of plain text source files into various output formats, automatically producing cross-references, indices, etc. That is, if you have a directory containing a bunch of [link]reStructuredText[/link] or [link]Markdown[/link] documents, Sphinx can generate a series of HTML files, a PDF file (via LaTeX), man pages and much more.
1ourp01ad97 p /html[1]/body[1]/div[3]/div[2]/section[1]/p[2]
  Sphinx focuses on documentation, in particular handwritten documentation, however, Sphinx can also be used to generate blogs, homepages and even books. Much of Sphinx’s power comes from the richness of its default plain-text markup format, [link]reStructuredText[/link], along with its [link]significant extensibility capabilities[/link].
23uo5n4rgfu p /html[1]/body[1]/div[3]/div[2]/section[1]/p[3]
  The goal of this document is to give you a quick taste of what Sphinx is and how you might use it. When you’re done here, you can check out the [link]installation guide[/link] followed by the intro to the default markup format used by Sphinx, [link]reStructuredText[/link].
080pi634ki7 p /html[1]/body[1]/div[3]/div[2]/section[1]/p[4]

  Defining document structure
0gfeeo9kby1 p /html[1]/body[1]/div[3]/div[2]/section[1]/section[2]/p[1]
  Let’s assume you’ve run *sphinx-quickstart*. It created a source directory with `conf.py` and a root document, `index.rst`. The main function of the [link]root document[/link] is to serve as a welcome page, and to contain the root of the “table of contents tree” (or *toctree*). This is one of the main things that Sphinx adds to reStructuredText, a way to connect multiple files to a single hierarchy of documents.
0ib7wpp1m7i p /html[1]/body[1]/div[3]/div[2]/section[1]/section[2]/div[1]/p[1]
  reStructuredText directives
1xlhd7qpeoz p /html[1]/body[1]/div[3]/div[2]/section[1]/section[2]/div[1]/p[2]
  `toctree` is a reStructuredText *directive*, a very versatile piece of markup. Directives can have arguments, options and content.
03zxpfucav9 p /html[1]/body[1]/div[3]/div[2]/section[1]/section[2]/div[1]/p[3]
  *Arguments* are given directly after the double colon following the directive’s name. Each directive decides whether it can have arguments, and how many.
1c3o3i581w3 p /html[1]/body[1]/div[3]/div[2]/section[1]/section[2]/div[1]/p[4]
  *Options* are given after the arguments, in form of a “field list”. The `maxdepth` is such an option for the `toctree` directive.
0l5umpon3me p /html[1]/body[1]/div[3]/div[2]/section[1]/section[2]/div[1]/p[5]
  *Content* follows the options or arguments after a blank line. Each directive decides whether to allow content, and what to do with it.
1pjvz83ajrl p /html[1]/body[1]/div[3]/div[2]/section[1]/section[2]/div[1]/p[6]
  A common gotcha with directives is that *the first line of the content must be indented to the same level as the options are*.

     :maxdepth: 2
0hlxym6f3h6 p /html[1]/body[1]/div[3]/div[2]/section[1]/section[2]/p[3]

     :maxdepth: 2

     usage/quickstart
     ...
0jz1nitjpph p /html[1]/body[1]/div[3]/div[2]/section[1]/section[2]/p[4]

0yxydcp8i9l p /html[1]/body[1]/div[3]/div[2]/section[1]/section[2]/div[4]/p[1]

0xk82mqwh2b p /html[1]/body[1]/div[3]/div[2]/section[1]/section[2]/div[4]/p[2]

22vgspjbaoa p /html[1]/body[1]/div[3]/div[2]/section[1]/section[2]/p[5]
  You can now create the files you listed in the `toctree` and add content, and their section titles will be inserted (up to the `maxdepth` level) at the place where the `toctree` directive is placed. Also, Sphinx now knows about the order and hierarchy of your documents. (They may contain `toctree` directives themselves, which means you can create deeply nested hierarchies if necessary.)

0tkqvf0okrx p /html[1]/body[1]/div[3]/div[2]/section[1]/section[6]/p[1]
  Earlier we mentioned that the `conf.py` file controls how Sphinx processes your documents. In that file, which is executed as a Python source file, you assign configuration values. For advanced users: since it is executed by Sphinx, you can do non-trivial tasks in it, like extending [link]`sys.path`[/link] or importing a module to find out the version you are documenting.
0bi70f3yla8 p /html[1]/body[1]/div[3]/div[2]/section[1]/section[6]/p[2]

To change the default value, remove the hash sign and modify the value. To customize a config value that is not automatically added by *sphinx-quickstart*, just add an additional assignment.
