# Scout — M6 storage, perf, i18n, diagnostics (2026-10-11, master @ ae9f9fb)

Read-only scout. These are facts with citations; the estimates are marked as such.

- **Storage.** `chrome.storage.sync` holds `schemaVersion`=1 (the only versioned item; providers.ts:48-89), `conn:<id>`, `profile:<id>`, `routing` (has `basicMigrated`), `siteRules` (one item), `siteAllowlist`, `siteNever` (sites.ts:20), `prefs`, `glossary`. `chrome.storage.local` holds `secret:<connId>`, `migratedRoute`, `spend`, `spendLimit` (spend.ts:14,19), `onboarding` (onboarding.ts:9) and `privacyNotice` (sidepanel/privacy.ts:10-12, value carries version 1). `chrome.storage.session` holds `tabRoute:<tabId>`, `snippet:<tabId>` (snippet.ts:37) and `access:<tabId>` (access.ts:37). Page localStorage holds `translate-side:scroll-follow` (follow.ts:16). The IndexedDB database `translate-side-cache` is opened at version 1 (cache.ts:147-154) with the stores segments, briefs and meta. Its cache keys embed `strategy@version` and the prompt ids (cache.ts:65-89).
- **Migrations.** Only `migrateProviders` exists (providers.ts:348-384). It is idempotent and runs from `background.ts:20-35` on install and from every `readProviderSettings` call (providers.ts:384). It handles M1 through `seedFromM1` and `migratedRouteFromM1`. Prefs, glossary, spend and the cache have no migration. Tests use in-memory fakes (providers.test.ts:178-330), and there are no stored JSON fixtures of old shapes. `scripts/eval/migration.ts` is a live harness for M1 and M2/M3 storage, and it is not in CI.
- **Quota.** `checkQuota` (providers.ts:398-430) checks per-item bytes, item count and total bytes for connections, profiles, routing (including siteRules, :503-505), quirks and import. The glossary guard is a separate implementation (settings.ts:322-390). The site allow and never lists (sites.ts:136-146) check only the 8 KB per-item limit and `MAX_SITES`=200, with no total-quota check. Estimates from the types: a connection takes about 400-700 B, a profile about 200-300 B, a site rule about 60-90 B, so one 8 KB `siteRules` item holds roughly 90-100 rules.
- **Diagnostics.** No job history is persisted; `JobView` (jobs.ts:93) lives in memory only. There is no error boundary and no window.onerror handler. Errors show through StateMessage.tsx:5. The M5 export (portable.ts:58-206) has reusable redaction helpers: `SENSITIVE_NAME` :70, `redactAddress` :115, `redactConnection` :136, `buildExport` :160 and `findSuspects`/`KEY_LIKE` :206.
- **i18n.** None of chrome.i18n, _locales or @wxt-dev/i18n is used. The only i18n call is `getUILanguage` (settings.ts:290). The manifest name and description are hardcoded (wxt.config.ts:14-15). Estimated user-visible strings: about 170-200. The JSX text is concentrated in Options 39, Providers 27, Onboarding 14, StateMessage 11 and Transfer 5, plus about 48 attribute strings and the shared error messages.
- **Performance.** `extractPage` runs synchronously (extract/index.ts:77). Nothing in src uses requestIdleCallback or yields. Lazy mode switches on at `LAZY_SEGMENTS`=400 (jobs.ts:443). The only measurement is in progress-m5.md:399-406: long-100-screens has 767 segments over 94.7 screens, and the longest task was 156 ms on a live run. No heap or memory figure is recorded, and there is no perf harness.
- **Bundle.** `.output/chrome-mv3`, built 11 Oct 08:22 (it may not match HEAD), raw/gzip in bytes: the openai chunk 367,366/82,190; anthropic 213,895/53,493; pricing 117,539/41,801; content.js 55,089/19,311; sidepanel 49,431/16,357; background.js 14,789/5,145. The total is 918,197 B raw. No numeric S7 budget is recorded. ROADMAP.md:62 says only "bundle budget", and progress-m1.md:73 says "137 kB gzip acceptable".
- **Version.** package.json:3 is 0.0.1. wxt.config.ts sets no version, and the manifest is built with 0.0.1.
- **Docs.** README sections: Why, Features, How it works, Getting started, Keyboard shortcuts, Useful scripts, Measured, Roadmap, Project layout, Contributing, License. There is no Ollama or LM Studio guide, no privacy page and no permission justifications. Privacy wording exists only in the app (PrivacyNotice.tsx:12-38). `docs/provider-matrix.md` is the M4-F eval matrix. Decision G5 (2026-10-09) replaced local LM Studio and Ollama with Ollama cloud.
- **Store assets.** public/ holds only icon/{16,32,48,128}.png. There are no store screenshots.
